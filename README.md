### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Make sure your system is fully updated for the best experience.

### How do I update the executors?

XCutors includes a built-in automatic update system. When you launch xCutorsLoader.exe, it will check for updates to all bundled executors and prompt you to install them.

### Can I use multiple executors at the same time?

You can switch between executors using the xCutorsLoader dashboard, but it is recommended to use only one executor per Roblox session to avoid conflicts.

### Where can I find scripts to use with XCutors?

### Do I need to disable my anticomponent software?

### How do I report bugs or request new features?

### Is XCutors compatible with Roblox updates?
